Guild Vigil — Font Programs · Round 01

Three licensed programs to replace the Georgia/Segoe stand-ins in tokens.css. Every block below renders identical desk content — same tokens, same materials — so only the type changes. All faces are SIL Open Font License (Google Fonts): free to embed in the single-file artifact and a future Tauri build, no fees, no seat limits.

Proposals only — nothing lands in tokens.css until you choose. Fonts load live from Google Fonts; if a block looks like Georgia, the CDN hasn't loaded.
