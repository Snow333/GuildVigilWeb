# Playtest notes

- **`<date>-<milestone>.md`** — one per milestone: what's new, what to try, known rough edges,
  whether saves broke. Steven's feedback and Hermes's triage table go in the same file.
- **`inbox/`** — raw in-game notes. In the game, press **✎ Note** (bottom right), type, save; the note
  lands in Downloads. Then `pnpm notes` (or just tell Hermes "collect my notes") moves them here.
